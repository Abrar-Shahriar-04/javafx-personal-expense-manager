# JavaFX Personal Expense Tracker

A desktop application designed to track, categorize, and manage personal expenses, built as a project for an Object-Oriented Programming (OOP) course.

## Features
* **Add Expenses:** Log title, monetary amount, category, and date.
* **Category Filtering:** Choose from pre-configured categories (Food, Transport, Utilities, Entertainment, Other).
* **Live Calculations:** Automatically updates the running total of all tracked expenses.
* **MVC Architecture:** Clean separation of concerns between Model (`Expense.java`), View (`expense-view.fxml`), and Controller (`ExpenseController.java`).

## Tech Stack
* **Language:** Java
* **UI Framework:** JavaFX & FXML (designed with Scene Builder)
* **Build Tool / IDE:** Maven & IntelliJ IDEA

## How to Run
1. Clone this repository or download the source code.
2. Open the project in **IntelliJ IDEA** (or any preferred Java IDE supporting JavaFX and Maven).
3. Ensure your JavaFX SDK/runtime dependencies are properly configured in your project structure.
4. Run the `Main.java` entry point to launch the application.
